# ФАКТОРАМА

Платформа перевірки фактів і медіаграмотності. Користувачі можуть надсилати на перевірку підозрілу інформацію або фейки.

Стек: Django 5.2, SQLite, Tailwind CSS.

## Вимоги

- Python 3.10 або новіший

## Запуск

1. Створіть віртуальне оточення та встановіть залежності:

   ```bash
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   ```

   На Windows замість `.venv/bin/` використовуйте `.venv\Scripts\`.

2. Створіть базу даних:

   ```bash
   .venv/bin/python manage.py migrate
   ```

3. Додайте адміністраторів:

   ```bash
   .venv/bin/python manage.py seed_admins
   ```

   Команду можна запускати повторно: вже наявних користувачів вона пропускає.

4. Додайте демонстраційні спростування для стрічки на головній сторінці:

   ```bash
   .venv/bin/python manage.py seed_refutations
   ```

   Команда завантажує зображення з інтернету й зберігає їх у папці `media/`. Якщо якесь зображення не завантажилося, запустіть команду ще раз: вона додасть лише відсутні зображення.

5. Запустіть сервер:

   ```bash
   .venv/bin/python manage.py runserver
   ```

6. Відкрийте в браузері:
   - http://127.0.0.1:8000/ — головна сторінка
   - http://127.0.0.1:8000/submit/ — форма надсилання фейку

## Структура проєкту

```
config/     налаштування Django та головні URL
pages/      головна сторінка, спільний шаблон, стилі та скрипти
reports/    заявки на перевірку фейків і спростування: моделі, сторінка форми, API, команда seed_refutations
users/      модель користувача та команда seed_admins
media/      завантажені зображення (не зберігається в git)
```

## База даних

- `users` — користувачі. Паролі зберігаються у вигляді хешу Argon2.
- `fake_reports` — заявки на перевірку. Статус: `pending` (ще не перевірено), `fake` (підтверджений фейк) або `not_fake` (не фейк). Поле `reviewed_by` вказує, хто з користувачів розглянув заявку.
- `refutations` — спростування фейків. Кожне спростування пов'язане з однією заявкою (`fake_report`) і містить заголовок, категорію, джерело поширення фейку, короткий опис, посилання на офіційне джерело, зображення та текст спростування. На головній сторінці показуються спростування до схвалених заявок.

Після зміни моделей створіть і застосуйте міграції:

```bash
.venv/bin/python manage.py makemigrations
.venv/bin/python manage.py migrate
```
